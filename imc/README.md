# IMC — Cálculo e Classificação

Exercício de lógica de programação e análise de dados em torno do Índice de Massa Corporal.

- [notebooks/01_eda.ipynb](./notebooks/01_eda.ipynb): análise exploratória do dataset [weight-height](https://www.kaggle.com/datasets/mustafaali96/weight-height) (Kaggle).
- [notebooks/02_transformacao.ipynb](./notebooks/02_transformacao.ipynb): conversão de unidades e renomeação de colunas.
- [notebooks/03_visualizacao.ipynb](./notebooks/03_visualizacao.ipynb): gráfico de dispersão do dataset já convertido.
- `data/`: arquivos CSV gerados pelos notebooks (dataset bruto e transformado).
